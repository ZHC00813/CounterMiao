# CounterMiao 4.3

[下载Windows 11 EXE安装包](https://github.com/ZHC00813/CounterMiao/releases/download/v4.3/CounterMiao-4.3-Setup.exe) · [发布说明与校验](https://github.com/ZHC00813/CounterMiao/releases/tag/v4.3) · [版本差异](CHANGELOG.md)

本次最终正式发布版本统一为 **4.3**，包含开发稿4.4.2的全部功能与修复，并增加EXE安装包。它与历史上111项测试的4.3开发稿不同。版本对应关系、历史差异和已知限制见 [VERSION_GUIDE.md](VERSION_GUIDE.md)，逐版修改见 [CHANGELOG.md](CHANGELOG.md)，测试证据见 [TESTING.md](TESTING.md)。

Win11 本地桌面程序。结构为 **报销批次 → 报销项 → 有名称的报销条目 → 发票、图片、其他附件**。4.1将类型选择移到新建报销项，并提供直接可见的条目编辑工作区；内部`project_id`和`entry_id`分别对应界面的报销项与报销条目，旧批次仍兼容。

## 运行与批次文件

推荐下载 `CounterMiao-4.3-Setup.exe`，双击选择中文或英文并完成安装。默认安装到当前用户的 Programs 目录，可修改目录，可选桌面快捷方式，通过开始菜单启动；Windows“设置 → 应用 → 已安装的应用”可卸载。安装和卸载不删除用户保存的批次或AppData工作资料。无需安装Python。

也提供便携版：完整解压后运行 `CounterMiao.exe`，保留 `_internal` 目录。

每次启动会选择中文或英文，之后也可在 Settings 中切换。首次导入前先新建报销项：选择零星采购、服务采购、物资采购或差旅报销，再填写名称。其下新建有名称的报销条目，条目自动继承上层类型。按当前报销条目导入/拖入发票或文件夹，子文件夹自动扫描。发票需核对，购买方默认深圳科创学院。

保存整个批次会生成单个 `.reimbatch` 文件，内含发票、图片、附件、结构和修改记录。文件可放在桌面或其他位置，使用“打开批次”（界面兼容旧按钮名时为“打开项目”）或拖入程序恢复编辑；也可把文件作为程序启动参数。未注册修改 Windows 默认文件关联。

保存时可选择密码加密，使用 AES-256-GCM 和 scrypt。密码至少 8 位，不存入批次，也不能找回。API Key、本机控制令牌、AI设置不随批次导出。本机编辑缓存和解密后的工作资料存于当前 Windows 用户的 AppData，文件加密不等于整个本机缓存加密。

关闭程序会提示保存、放弃另存或取消关闭。Windows 正常关机/注销时安装保存提示钩子；没有实际触发设备关机测试，也无法在强制断电后弹窗。自动保存支持关闭、1/5/60分钟或自定义分钟数；未命名批次的自动保存副本位于 `%LOCALAPPDATA%\报销项目助手\自动保存批次`，已指定文件则保存到该文件。加密批次的自动保存继续使用本次会话密码。关闭自动保存后不进行定时批次保存，也停止自动写入工作库；手动保存仍有效。

## 拖放与批量操作

支持右键展开菜单：材料列表提供分类导入、打开、核对、移除，以及“选择操作 → 全选 / 反选 / 取消全选”；总览及上传按钮提供“上传材料”子菜单。右键已选文件保留多选结果，右键未选文件切换到该文件。

发票、配图和附件列表支持单选、Ctrl/Shift多选、Ctrl+A全选以及“全选 / 反选 / 取消全选”。文件选择窗口也支持一次选取多个文件。选中的发票可连续核对；图片及附件可批量打开或移除关联，原文件保留。

在“发票配图”页选择对应发票后，可直接拖入多张图片或整个图片文件夹；子目录自动扫描并按内容去重。图片不自动分配给多张发票。

在“其他附件 / 签字件”页选择材料类别后，可直接拖入文件或文件夹；拖到具体材料行时按该行类别归集。拖入的图片与附件不会被误导入成发票。

报销项总览中，发票、配图和附件上传入口采用可点击、可键盘聚焦的圆角矩形按钮，也可拖到对应按钮；附件拖入后先选择类别再导入。按钮随表格滚动、缩放更新，普通单元格点击仅选择。

## 工作区与界面

固定底部操作区，材料表格按剩余空间伸缩；总览七列随窗口调整，金额右对齐并保留两位小数，无法识别的金额显示待核对。项目树上方保留新建入口，低频功能集中在底部“批次与工具”。

所有页面使用统一品牌页眉、绿色主要按钮、中性次要按钮、移除操作和面包屑。配图列表显示缩略图；没有发票或条目时显示下一步引导。

底部“生成本报销项表单”作用于当前报销项；“更多操作”包含整批归档、手动完成、全部检查、规则说明及AI接口。批次文件保存状态与条目内容更新分别提示。设置使用明确的自动保存档位，并支持自定义分钟数。

## 报销项统一表格

单击左侧报销项，右侧显示该项下全部报销条目和发票，每张发票一行。点击“新建报销条目”可新增；双击条目名称、企业名称或用途单元格直接编辑，按Enter或离开单元格保存。双击金额打开发票核对窗口。点击发票、配图或附件列可给该行对应的条目添加材料，附件可选择所需材料类别。改企业名称后需重新核对发票。点击左侧具体报销条目则立即切换到该条目的编辑区。

## 条目内容编辑

单击左侧报销条目，右侧可修改名称和用途，点击“保存条目修改”。在“发票与内容修改”页导入发票或文件夹；双击发票（或选中后点“核对 / 修改发票内容”）修改金额、销售方、日期和明细。在“发票配图”页选择对应发票后添加多张图片；“其他附件 / 签字件”页选择材料类别后添加文件。切换条目和保存批次时也会保存正在编辑的名称、用途。

旧版混合类型报销项保留原内容；新增同类型报销条目请建立明确类型的新报销项。

## 树形管理

左侧始终展示批次、报销项和报销条目；展开可看发票、配图及附件，双击文件用系统默认应用打开。上层入口叫“新建报销项”，其下叫“新建报销条目”。右键还支持删除、标红、隐藏、显示父子关系箭头。删除进入回收站，文件原件不删除；隐藏不会排除报销检查或金额合计，可勾选显示隐藏项恢复。两级名称均可修改。

每张发票必须归属一个有名称的报销条目。同一报销项内、相同类型的报销条目可按金额/实际明细数规则合并验收单；服务采购始终一票一单。签字扫描件按每份规划验收单编号关联。不同报销项不混为一张验收单。

## 四类规则

| 类型 | 金额与制单 | 必需材料 |
|---|---|---|
| 零星采购 | 单票≤1000；同供应商同自然月合计≤1000，票数不限；每份≤5000、最多15个实际明细 | 发票、每份签字验收单 |
| 服务采购 | 单票≤5000；一票一单，最多15个明细 | 发票、服务类采购申请、每份签字验收单 |
| 物资采购 | 单票及每份验收单≤5000、最多15个明细 | 发票、采购申请/审批、采购入库材料、每份签字验收单 |
| 差旅报销 | 金额及明细数量不限；生成差旅表、不生成采购验收单 | 发票、行程单、行程申请、调研申请；电子登机牌可另附 |

零星月度规则覆盖当前批次中已加载的所有项目，优先使用销售方税号，缺少税号时按名称匹配；日期须为 `YYYY-MM-DD`。程序不读取未加载的其他批次以累计。票据种类、名称、日期及含税明细无法可靠识别时需要补录，不会编造。当前服务采购沿用采购验收模板。

采购类每票可选多张图或无图。无图不留空位、不写缺图标识。图片不影响必需附件检查。合格/不合格方框、验收日期和签字不由程序代填。

检查确认文件存在、非空、可读取及关联是否齐全，不自动判断签字真假、审批是否有效或上传文件内容是否匹配。手动完成和自动检查是两个独立状态。发票变化影响验收内容时需重新关联适用的签字件。

## 导出

- 金额清单：当前报销项逐票金额、已识别合计及未识别数量，CSV可用Excel打开。
- 分组导出：当前项目所选类型的Word验收单或差旅表格。
- 导出文件清单：可选择树中当前项目/报销项或整个批次，按项目分色列出小报销项、单票金额、总额、已有/缺失材料及文件路径。
- 归档：新目录及ZIP，按项目与小报销项复制相关文件，包含项目总览、发票明细、附件索引及可恢复项目数据。原文件不移动、不删除。未通过检查时只可明确选择导出整理草稿，问题进入独立清单。

“修改记录 / History”查看时间、变更字段、前后值和哈希记录，记录随批次保存。记录用于本地溯源，不是数字签名，不能防止有意重写整个历史。

## 内置AI与外部操作

打开 AI/API 面板，填写服务商、Base URL、模型ID、API Key。Key使用Windows当前用户DPAPI加密保存在本机。没有预置真实收费密钥，也不会替用户申请账户。

预置OpenAI兼容、DeepSeek、Kimi国内/国际及Claude Messages请求格式。服务商模型ID需要自行填写。点击发送前提示项目名称、报销项、票号和金额元数据的接收地址；不自动上传原发票或图片。AI返回操作计划，用户查看并执行。删除可恢复；发票金额和签字不可由AI伪造。

本机HTTP接口默认关闭，仅绑定127.0.0.1，需Bearer令牌，默认只读。启用写入后可由外部工具管理项目、报销项、标记、附件、检查、导出和可恢复删除。API权限开关可随时收回。详见 [AI_INTERFACE.md](AI_INTERFACE.md)。另提供 `CounterMiaoMCP.exe` 作为stdio MCP适配器，供支持MCP的Codex、Claude等客户端配置；没有自动修改这些客户端设置。

AI服务商在线调用尚未用真实账户验证，接口请求及安全边界使用本机模拟服务测试。服务可用性、模型授权和计费取决于用户的服务账户。

## 开发与验证

Python 3.12。安装 `requirements.txt` 后运行 `python app.py`；构建便携版用 `build.ps1`；安装官方 Inno Setup 6.7 后，运行 `build.ps1 -Installer -IsccPath "ISCC.exe的完整路径"` 同时生成安装包。安装脚本为 `installer.iss`，输出在 `installer-output`。测试用 `python app.py --self-test <新的测试目录>`，仅生成模拟材料。测试报告与版本差异随发布包提供。

真实桌面测试材料仅用于本地验证，不进入源码、程序包、批次示例或GitHub。旧版本压缩包在本地保留，具体路径见版本索引。正式源码及安装包发布到 https://github.com/ZHC00813/CounterMiao 。

第三方许可随程序提供，源码仓库汇总见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)。仓库发布许可证由所有者确认，正式发布前应核对依赖许可和单位模板的发布权限。
